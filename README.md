# 🤖 Arab AI

منصة الذكاء الاصطناعي العربية المتخصصة في مساعدة المبرمجين. موقع تفاعلي وسريع يوفر أدوات ذكية لكتابة، مراجعة، وتصحيح الأكواد البرمجية.

## ✨ المميزات

- 💬 **محادثة ذكية**: اسأل عن أي مفهوم برمجي واحصل على إجابات واضحة.
- ⚡ **توليد الأكواد**: اكتب وصفاً لما تريد، واحصل على كود جاهز بعدة لغات (Python, JavaScript, Java, C++, PHP).
- 🔍 **مراجعة الأكواد**: حلّل كودك الحالي واحصل على اقتراحات لتحسين الأداء والأمان.
- 🐛 **كشف الأخطاء**: الصق الكود ورسالة الخطأ، وسنساعدك في إيجاد الحل وتصحيحه.

## 🛠️ التقنيات المستخدمة

- **HTML5 / CSS3**: لبناء واجهة مستخدم عصرية، متجاوبة، وتدعم الوضع الليلي (Dark Mode).
- **JavaScript (Vanilla)**: لإدارة تفاعلات الموقع ومنطق التطبيق بدون أطر عمل ثقيلة.
- **Marked.js**: لعرض ردود الذكاء الاصطناعي بتنسيق Markdown بشكل جميل.
- **Highlight.js**: لتلوين الأكواد البرمجية (Syntax Highlighting) لجعلها سهلة القراءة.

## 📌 ملاحظة هامة

هذا الإصدار يستخدم ردوداً تجريبية (Mock Responses) لعرض واجهة المستخدم وتجربة التدفق. الخطوة القادمة هي ربط الموقع بـ **NVIDIA NIM API** أو أي مزود ذكاء اصطناعي آخر للحصول على ردود حقيقية وديناميكية.
